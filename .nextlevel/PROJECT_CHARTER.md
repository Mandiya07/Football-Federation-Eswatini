# PROJECT CHARTER

## Project Name
Football Federation Eswatini (FFE) Platform & Indvundvundvwane Major Football League

## Mission
Establish a self-reliant, meritocratic, and high-performance digital operating platform for the Football Federation Eswatini (FFE) and the private Indvundvundvwane Major Football League, establishing professional operations, transparency, club-owned equity, grassroots talent incubation, and regional talent mobility outside of FIFA national team mandates.

## Core Stakeholders
- **Affiliated Football Clubs**: Sole voting members and primary shareholders of the professional league.
- **FFE Founders**: Lifelong honorary deliberative members (5 founders).
- **Independent Eligibility Committee**: Incorruptible vetting authority for all appointments and elected candidates.
- **Indvundvundvwane Major Football League Board**: 5 to 7 club-elected directors overseeing executive management.
- **Players, Coaches, Referees, and Supporters Unions**: Recognized affiliate bodies permitted to make representations without voting power.
- **Nursery & Academy Athletes**: 3-tier developmental cohort from age 1 through 18.

## Technology Stack
- **Client Application**: React 19, TypeScript ~5.8.2, Vite 6, Tailwind CSS 4, React Router v7.
- **UI System**: Lucide React, Radix UI primitives / Base UI, Motion.
- **Backend / BaaS**: Firebase Authentication (Google OAuth), Cloud Firestore, Cloud Storage.
- **Deployment Platform**: Cloud Run / Vercel SPA target.
